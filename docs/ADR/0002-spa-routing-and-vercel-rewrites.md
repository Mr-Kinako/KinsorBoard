# ADR-0002: Маршрутизация через react-router и fallback rewrite в vercel.json

* **Статус:** Принято
* **Контекст:** Приложение использует клиентскую маршрутизацию (`BrowserRouter`, `Routes`, `Route` из пакета `react-router`), в том числе маршрут `/board`. При прямом заходе или обновлении страницы на вложенном пути статический хостинг без fallback возвращает `404`.

## Решение

1. Использовать пакет `react-router` для клиентской маршрутизации приложения.

2. Добавить в корень репозитория `vercel.json` с правилом `rewrites`, перенаправляющим `/(.*)` на `/index.html`.

## Последствия

- **Плюсы:** Прямые переходы на `/board` и перезагрузка страницы работают корректно на деплое.
- **Минусы / компромиссы:** При проверке локально через статический сервер без SPA-fallback поведение может отличаться от продакшена на Vercel.
